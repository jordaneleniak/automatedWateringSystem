# STM32 Implementation

This folder contains the STM32 (L432KC) version of the automated watering system.

## Purpose

This stage focuses on transitioning from Arduino to a more advanced embedded system platform, enabling:

- finer hardware control
- direct use of peripherals (ADC, GPIO, timers)
- improved system performance and scalability

## Status

Initial project generated using STM32CubeIDE.

Implementation in progress.
